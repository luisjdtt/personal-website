Roddy AI-Agent Platform

Plataforma B2B multi-tenant para agentes de IA, flujos serverless e integraciones empresariales

Rol

Technical Lead / Arquitecto de Software

Periodo

2025 - Presente

Tecnologías

AWS Lambda, API Gateway, DynamoDB, SQS, S3, CloudFront, AWS SAM, TypeScript, React, Python, Django, Odoo, Epicor, WhatsApp, LLMs

Resumen del Proyecto

Roddy es una plataforma B2B multi-tenant de agentes de IA usada por clientes reales para automatizar procesos de ventas y operación en WhatsApp, email, webchat, ERPs, CRMs y sistemas internos.

Diseñé y construí la superficie técnica principal de la plataforma: backend serverless en AWS, portal de clientes en React/TypeScript, middleware, autenticación, integraciones, despliegue, documentación y configuración de producción.

Arquitectura

Backend Serverless

Backend con AWS SAM, 50+ funciones Lambda, 30+ tablas DynamoDB, 8 colas SQS, API Gateway, S3, CloudFront, Lambda Layers, procesamiento asíncrono y flujos event-driven.

Portal para Clientes

Portal en React/TypeScript para gestionar clientes, usuarios, agentes, canales, conexiones, casos de uso, webhooks, eventos, reglas de notificación, dashboards y web chat.

Runtime de Agentes de IA

Configuración dinámica, herramientas reutilizables, casos de uso configurables, mensajería multi-canal, aislamiento por cliente y orquestación extensible de agentes.

Integraciones Empresariales

Integraciones con Odoo, Epicor, middleware ERP, WhatsApp, email, webchat, Google Calendar, Google Spaces y flujos específicos por cliente.

Impacto

Roddy opera en producción con aproximadamente 7 clientes B2B, procesando 100+ contactos por día y varios miles de mensajes automatizados por mes.

Para una gran distribuidora mexicana de artículos de oficina, la plataforma ayudó a automatizar flujos de ventas de menor contacto, reducir trabajo manual del equipo comercial y habilitar respuestas automáticas 24/7.

  • Arquitectura serverless en AWS para producción
